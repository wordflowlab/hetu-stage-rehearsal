# Skill与机器接续

包内hetu-stage-rehearsal由河图动态发现，不创建Codex插件、独立MCP服务器或客户端工具名。安装和启用后重新读取活动包摘要、capabilities与skills.read；旧能力绑定不得继续使用。业务无需启动桌面。

默认旅程：读取固定剧本 → 段落与部门提示 → 核对调用依赖 → 比较提示编排 → 保存手动排演记录 → 复核改稿影响 → 提示本与固定交接。先读已有工程、固定作品及意见，不新建另一份演示工程替代接续。方法由Skill维护，确定性规则由专业后端执行。

固定引文只追加。提示绑定明确段落和触发说明，部门与调用依赖可核对；依赖循环、出场ID或顺序重复和计划中倒置依赖拒绝；同一提示可有多个独立出场。计划固定实际使用的段落、提示及顺序组合摘要；改稿后旧计划与意见待复核。排演记录包含完整专业快照，旧记录不可覆盖，手动记录的时间与结果不冒充设备回执。估时和现场手记分列；不以计划完成认定演出完成。

每阶段保存并回读固定修订，create_handoff记录依据、目标与未解决问题。其他插件根据实际安装能力独立发现，通过固定专业引用组合。未知先回读，正文采纳、定稿、内容外发与费用按作者确切决定执行。

SKILL.md作为精炼方法入口，references/workflows.md提供专业方法与反例，operations.md从正式清单生成。专业清单由本仓库维护，宿主40只导航动态入口。
