# 舞台排演

先发现当前已启用包、真实Schema和同包方法，携带确切WorkRef、management_ref及活动包／能力摘要。先读取固定作品、已有工程、来源、成果和意见，不重复创建或要求作者手填。

读取固定剧本 → 段落与部门提示 → 核对调用依赖 → 比较提示编排 → 保存手动排演记录 → 复核改稿影响 → 提示本与固定交接。

固定引文只追加。提示绑定明确段落和触发说明，部门与调用依赖可核对；依赖循环、重复出场和计划中倒置依赖拒绝。计划固定实际使用的段落、提示及顺序组合摘要；改稿后旧计划与意见待复核。排演记录包含完整专业快照，旧记录不可覆盖，手动记录的时间与结果不冒充设备回执。估时和现场手记分列；不以计划完成认定演出完成。

宿主剧本保存正式文本，导演布景台负责空间与机位，本包负责现场提示本和排演复盘。不控制灯光、音响或舞台机械，不承担现场安全调度和对外演出发布。

[流程与反例](references/workflows.md)提供专业方法；[操作地图](references/operations.md)从正式清单生成。每阶段保存后回读固定修订；未知先get_operation，CAS保留原输入。用create_handoff接续下一阶段，正文采纳、定稿、外发与费用分别按确切作者决定。
